# BreakPoint

Classic Breakout-style game built with HTML5 Canvas and vanilla JavaScript.

Run: open `breakpoint/index.html` in your browser.

Controls:
- Left Arrow / Right Arrow: move paddle
- Space: start / restart

Project structure:

- `index.html` — game canvas and HUD
- `style.css` — basic styling
- `js/` — modular game code (paddle, ball, bricks, collision, ui, game)
- `assets/` — images and sounds placeholders

This initial version is a traditional Breakout clone. The impossible-to-win mechanics will be added later.
